Writes like C++. Runs like C++. Feels beyond C++.

All for development speed and user experience. Solo is more.

Get started ↗GitHub ↗

What you can do

Requirements

Use stock Unreal Engine without compiling the engine, with a straightforward environment setup.

Rapid iteration

Develop with instant feedback and automatic script reload.

Peak performance

Compile supported scripts to native C++ for release, with very little performance loss.

Beyond typical scripting (coming soon)

Smart pointers, raw pointers, async, multithreading and lambdas give AS almost unlimited possibilities.

Feature Mods (coming soon)

Use AS scripts to build Feature Mods, combine projects like building blocks and deliver hot updates.

Automatic binding (coming soon)

Automatically turn UE C++ module APIs into script APIs with broad coverage, including APIs outside the reflection system.

Start with your own project

Documentation ↗

  1. Install soloAS

    Download and extract into your project’s Plugins/, keeping its folder layout.

  2. Choose your features

    Enable plugins such as GAS and Enhanced Input as needed.

  3. Write a script

    Put a .as file in Script/; it reloads on save, so you can test right in the editor.

Roadmap

The items below are planned directions; their scope, order and release may change.

Note: soloAS is developed by an independent game developer working with a team of AI agents. The key technical problems behind every upcoming feature have already been solved, but limited compute and personal time leave a lot of smaller testing and verification work, so no schedule is guaranteed. Contributing and giving back

soloAS is open source. To help the project get something back, we make an attribution request and invite you to share your project; neither is mandatory. You are welcome to report problems and open issues in the repository, and more contributors are welcome.

Attribution request

If your project uses soloAS, we would appreciate a note saying "Uses soloAS" in your credits, store page, README or website, with a link to the soloAS website or repository. This is not a license requirement; we simply value the gesture.

Showcase

If a public project states that it uses soloAS, we may list it as a showcase, showing only its name, a short description and public screenshots or links, never in a misleading way. Owners can ask for changes or removal at any time. You are also welcome to let us know that your project can be showcased.
