soloAS，
为设计而生的 Unreal 脚本系统

写得像 C++，跑得像 C++，体验超 C++。

一切为了开发效率与用户体验，单即是多。

开始使用 ↗GitHub ↗

能做什么

使用要求

使用原版 Unreal Engine，无需编译引擎，环境搭建简单。

高速迭代

即写即反馈，脚本自动重载，让开发更流畅。

极致性能

发布时可将支持的脚本编译为原生 C++，性能损失很低。

超模脚本（待发布）

智能指针、裸指针、异步、多线程与 Lambda，让 AS 拥有近乎无限的可能。

功能模组（待发布）

利用 AS 脚本的特性实现功能模组，像搭积木一样构建项目，支持热更新。

自动绑定（待发布）

将 UE C++ 模块 API 自动转为脚本 API，覆盖广泛，反射系统之外的 API 也能转换。

从自己的项目开始

使用文档 ↗

  1. 安装 soloAS

    下载并解压到项目的 Plugins/，保留目录层次。

  2. 选择要用的功能

    按需启用 GAS、Enhanced Input 等插件。

  3. 写一个脚本

    把 .as 文件放进 Script/，保存即自动重载，直接在编辑器中测试。
