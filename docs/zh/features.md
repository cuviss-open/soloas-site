# 功能一览

## 核心

在原版 Unreal Engine 中使用 AngelScript，编写脚本类和组件，在编辑器中热重载，并使用 GAS 和 Enhanced Input。详见[插件核心](core.md)和[手工绑定包](manual-binding-packs.md)。

## 核心扩展

以下功能默认开启，也可以单独关闭。详见[核心扩展](extensions.md)。

- **UE 接口**：脚本可以实现 C++、AS 和蓝图接口，编辑器脚本还能新建接口供蓝图实现。
- **蓝图继承**：脚本类可以直接继承蓝图父类。
- **蓝图结构体**：在脚本里使用蓝图中定义的结构体。
- **原生事件的父类实现**：重写原生事件时可以调用 Unreal 父类的原始实现，保留默认行为。
- **lambda**：为委托和容器算法编写 lambda，用显式捕获指定变量。

## 开发工具

详见[项目打包](packaging.md)和 [AI 辅助开发](ai-assisted.md)。

- **字节码打包**：发布包不带 AS 源码，启动时也不用再预处理和编译脚本。
- **半 AOT 打包（static JIT）**：把可生成的 AS 函数转成 C++ 编进游戏，减少虚拟机开销。
- **命令行与 CI 打包**：用插件自带的打包脚本检查和执行打包，和编辑器读同一份项目设置。
- **MCP 辅助开发**：AI 通过 MCP 读取脚本类型和工程信息、协助打包、调试脚本。
