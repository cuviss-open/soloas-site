# 社区贡献

## 项目许可证

各插件的许可证见下表。请保留项目及第三方组件随附的许可文本与版权通知。

分发包含 MPL-2.0 所覆盖代码的编译后项目时，须按 [MPL-2.0](https://www.mozilla.org/en-US/MPL/2.0/) 告知接收者如何获取相关源码。

| 插件或组件 | 许可证 |
| --- | --- |
| AngelscriptRuntime（包含 AngelScript 库） | MIT；其中 AngelScript 库为 zlib |
| AngelscriptGAS | Apache-2.0 或 MIT，任选其一 |
| AngelscriptEnhancedInput | MIT |
| soloAS 其他除上方外的所有内容 | MPL-2.0 |

注：凡是从 UE Haze fork 继承来的插件，我们对其所做的修改沿用该插件原有的许可证；除此之外，皆为 MPL-2.0。

完整条款以随附的许可文件为准。

## 参与项目

通过 [soloAS 仓库](https://github.com/cuviss-open/soloAS)交流。

### 报告问题

请在仓库提交 issue，说明问题、预期行为，并提供最小复现。

### Pull request

保持改动聚焦，说明用户可见的结果，以及如何在原版 UE 上验证。涉及 Runtime 或 Bridge 时，适用的改动还应检查非编辑器 Game 构建。附上引擎版本和平台，方便审查者复现。

### DCO 签署

贡献采用 Developer Certificate of Origin 1.1（DCO）签署。每个提交使用：

```sh
git commit -s
```

签署前阅读 [Developer Certificate of Origin](https://developercertificate.org/)，并使用贡献者本人的身份；签署记录你对该贡献所作的证明。

## 贡献与回馈

soloAS 开源。为了让项目获得开源回馈，我们诚恳提出致谢请求，并邀请你分享案例；两者都不具有强制性。欢迎在[仓库](https://github.com/cuviss-open/soloAS)反馈问题、提交 issue，也欢迎更多人参与贡献。

### 致谢请求

如果你的项目使用了 soloAS，希望你在鸣谢名单、商店页面、README 或官网中注明“使用了 soloAS”，并附上 [soloAS 网站](https://soloas.cuviss.com)或[项目仓库](https://github.com/cuviss-open/soloAS)的链接。这不是许可证的强制条款，我们很感谢这样的回馈。

### 案例展示

对于已公开并说明使用了 soloAS 的项目，我们可能将其列为使用案例，只展示项目名、简介和公开的截图或链接，不做误导性描述。项目方可随时要求修改或撤下，也欢迎主动告知项目可用于展示。
