# 不同 UE 版本的适配差异

适用于 soloAS 0.1.3。

此表格记录 soloAS 适配 UE 旧版本与最新版本的差异，以 soloAS 适配的最新版本为准。

## 核心双插件

| 差异 | 受影响版本 | 影响范围 | 说明 | 体验影响 |
| --- | --- | --- | --- | --- |
| 混合复制属性的发送时机 | 5.4、5.5、5.6 | 游戏运行时 | UE 5.4 至 5.6 对混合普通复制与标记复制属性的对象，会继续检查整组属性；UE 5.7 起可单独检查其中标记复制的属性。 **UE-AS fork 在这些版本同样如此。** | 在 UE 5.4 至 5.6 中，即使属性未标记变更也可能发送。需要严格控制未标记属性不发送时，使用通用复制方式或升级至 UE 5.7 及以上版本。 |
| 原生资源释放清理回调 | 5.4 | 游戏运行时 | UE 5.4 没有该原生清理回调，脚本析构时载荷仍有效。 **UE-AS fork 在这些版本同样如此。** | 5.4 脚本析构中仍可观察有效载荷；派生析构抛出异常时，基类载荷清理可能跳过。避免在析构中抛异常，或在正常流程显式释放载荷；需要析构前原生清理时使用 5.5 及以上版本。 |
| 外部化容器覆盖状态 | 5.4、5.5、5.6、5.7 | 仅编辑器 | UE 5.4–5.7 缺少外部化覆盖状态。5.4/5.5 中 soloAS 提前明确拒绝 Externalized 操作；5.6/5.7 中引擎发出警告并忽略该操作，值按普通覆盖导入。 **UE-AS fork 在这些版本同样如此。** | 需要保留外部化语义时，请使用支持外部化的新版编辑器。 |
| null 对象键的 Map 增量覆盖 | 5.5 | 仅编辑器 | 覆盖文本导入遇到 null 对象 Map 键时，UE 5.5 会提前明确拒绝该键；最新版本会直接触发原生断言。 **UE-AS fork 在这些版本同样如此。** | 5.5 中该键不会被导入，编辑器不会因此崩溃。非空键不受影响。 |
| ListView 滚动插值速度 | 5.4 | 仅编辑器 | UE 5.4 没有新版的滚动插值速度字段和设置接口。 **UE-AS fork 在这些版本同样如此。** | 使用原生固定滚动行为，不能配置该速度；常规条目和滚动不受影响。 |
| Python 访问已删除的脚本类型 | 5.4 | 仅编辑器 | UE 5.4 编辑器 Python 没有回收旧类型的入口，删除或重命名脚本类后可能保留旧类型包装。 **UE-AS fork 在这些版本同样如此。** | 重启编辑器后再通过 Python 访问；游戏运行不受影响。 |

## GAS

| 差异 | 受影响版本 | 影响范围 | 说明 | 体验影响 |
| --- | --- | --- | --- | --- |
| 旧版游戏标签复制设置 | 5.4、5.5、5.6 | 游戏运行时 | UE 5.4–5.6 引擎没有复制计数设置。soloAS 在这些版本提供与 UE 5.8 相同的参数，其中 None 可用，TagOnly 按服务端权威调用对齐；CountToOwner、TagAndCountToAll 需 UE 5.7 及以上，SimulatedTagOnly 需 UE 5.8 及以上，否则会明确报错。 **UE-AS fork 在这些版本同样如此。** | 旧版本可用 None/TagOnly；计数复制模式需升级引擎。客户端预测时父标签计数可能与 5.8 不同。 |

## 增强输入

目前没有已确认的用户可见差异；这不代表所有旧版本的行为均已验证。
